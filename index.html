Automatizo tareas repetitivas que tu equipo hace a mano: recorrer una web, apuntar precios, exportar un catálogo, convertir tablas en Excel. Cada proyecto se entrega con demo real ejecutada (datos en CSV/Excel incluidos), no con un ejemplo teórico.

Cómo trabajo

  1. Cuéntame la tarea manual que repites (exportar un catálogo, apuntar precios, copiar una tabla web a Excel…).
  2. Te hago una demo con tu tipo de datos en 1-2 días: la misma estructura que los repos de arriba, adaptada a tu caso.
  3. Entrego script + datos en Excel/CSV + instrucciones para que tu equipo lo ejecute sin depender de mí.

Tecnología: Python (Selenium, requests, BeautifulSoup, openpyxl). Sin licencias de pago. Trabajo remoto (ES/UK).

Por qué demos ejecutadas y no capturas

Cada repo contiene el código completo, los datos que generó una ejecución real y sus instrucciones de uso. Puedes clonarlo y ejecutarlo tú mismo en un minuto: pip install -r requirements.txt y python. Eso es la garantía: el resultado que ves es el resultado que obtienes.
